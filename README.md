# Smakolandia

Smakolandia – Twoje kulinarne centrum odkryć! Witamy w Smakolandia, miejscu, gdzie każdy przepis staje się niepowtarzalnym doświadczeniem! Nasza aplikacja łączy pasjonatów gotowania, amatorów i profesjonalnych szefów kuchni w jednym miejscu. Przygotuj się na odkrycie nowego wymiaru gotowania!

## How to run?

- Go to node-server directory and run `npm run webpack`
- Go to react-app directory and run `npm run start`

## Wymagania funkcjonalne

- Zarządzanie przepisami: dodawanie, edytowanie, usuwanie.
- Wyszukiwanie przepisów według składników, kategorii, czasu przygotowania.
- Generowanie listy składników z podziałem na dostępne i brakujące.
- Przeliczanie składników na podstawie liczby porcji.
- Personalizacja: lista ulubionych przepisów.
- Responsywność strony na urządzeniach mobilnych.

## Wymagania niefunkcjonalane

- Strona musi ładować się w czasie poniżej 3 sekund.
- Skalowalność: możliwość łatwego rozwoju.
- Zgodność z najnowszymi wersjami popularnych przeglądarek.

## Potencjalne ryzyka

- Brak doświadczenia w tworzeniu baz danych.
- Ograniczona znajomość frameworków do frontendu (np. React, Angular).
